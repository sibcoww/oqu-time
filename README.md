# SchoolScheduler

SchoolScheduler — локальное Windows-приложение для автоматического составления школьного расписания.

> **Статус проекта:** проект находится в разработке и пока не является завершённым продуктом. Основные функции реализованы, но программа ещё требует проверки на реальных школьных данных, доработки интерфейса и дополнительного тестирования.

## Что уже реализовано

- первоначальная настройка школы, учебной недели, смен и расписания звонков;
- ведение классов, учителей, предметов и кабинетов;
- стандартный набор школьных предметов при первом запуске;
- единый импорт данных из Excel;
- проверка исходных данных и вывод найденных проблем;
- автоматическое составление расписания с помощью Google OR-Tools;
- учёт занятости учителей, классов, групп и кабинетов;
- учёт смен, нулевых уроков и доступности ресурсов;
- параллельные занятия для разных групп одного класса;
- четырёхнедельный цикл для дробной нагрузки;
- ручное изменение и закрепление занятий;
- повторная оптимизация расписания;
- просмотр расписания по классам, учителям и кабинетам;
- экспорт в Excel и PDF, печать;
- резервное копирование и восстановление проекта;
- проверка по настраиваемым нормативным правилам Республики Казахстан;
- Windows-установщик.

## Импорт из Excel

Импорт запускается во вкладке **«Учителя»** кнопкой **«Импорт данных из Excel»**.

Из файла автоматически загружаются:

- учителя;
- предметы и их короткие названия;
- классы;
- кабинеты;
- группы;
- количество часов в неделю;
- разрешение нулевого урока;
- учебная нагрузка.

Поддерживается нормализованный лист **«По классам»** со столбцами:

`ФИО учителя`, `Предмет`, `Короткое название`, `Класс`, `Часов в неделю`, `Кабинет`, `Группа`, `Нулевой урок`.

Повторный импорт не создаёт одинаковые справочные записи. Найденные строки нагрузки обновляются.

## Дробная нагрузка

Если в нагрузке есть дробные часы, программа создаёт расписание на четыре недели:

- `0,25` — один урок за четыре недели;
- `0,5` — один урок в двух неделях из четырёх;
- `0,75` — один урок в трёх неделях из четырёх;
- целые часы повторяются каждую неделю.

После генерации нужная неделя выбирается на экране расписания.

## Требования для разработки

- Windows 10 или Windows 11;
- .NET 10 SDK;
- Visual Studio с поддержкой WPF — необязательно, но удобно для разработки;
- Inno Setup 6 — только для сборки установщика.

## Запуск

В корне репозитория выполните:

```powershell
dotnet restore SchoolScheduler.slnx
dotnet run --project SchoolScheduler.App
```

Или откройте `SchoolScheduler.slnx` в Visual Studio, назначьте `SchoolScheduler.App` запускаемым проектом и нажмите `F5`.

## Тесты

```powershell
dotnet test SchoolScheduler.slnx
```

## Сборка установщика

Для production-сборки нужен Inno Setup 6:

```powershell
.\installer\build-installer.ps1
```

Готовый self-contained установщик Windows x64 создаётся в каталоге `artifacts\installer`. Установленная программа не требует отдельной установки .NET.

Пользовательская база хранится здесь:

```text
%LocalAppData%\SchoolScheduler\data\school.db
```

При обновлении программы база сохраняется.

## Структура решения

- `SchoolScheduler.App` — интерфейс Windows-приложения;
- `SchoolScheduler.Core` — основные сущности школы;
- `SchoolScheduler.Data` — база данных SQLite;
- `SchoolScheduler.Scheduling` — проверка и генерация расписания;
- `SchoolScheduler.ImportExport` — работа с Excel, PDF и печатью;
- `SchoolScheduler.Tests` — автоматические тесты;
- `installer` — сборка Windows-установщика.
